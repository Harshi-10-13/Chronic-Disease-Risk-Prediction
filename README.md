📊 Chronic Kidney Disease (CKD) Analysis using Python

📖 About the Project

This project is part of my Data Analytics learning journey. It focuses on understanding, cleaning, and analyzing a Chronic Kidney Disease (CKD) dataset using Python. The project is divided into two phases: Week 1 (Data Preprocessing) and Week 2 (Exploratory Data Analysis).

---

🎯 Project Goals

- Prepare raw healthcare data for analysis.
- Improve data quality through cleaning techniques.
- Explore patterns and relationships in the dataset.
- Create meaningful visualizations.
- Gain practical experience in Python-based data analysis.

---

🧰 Tech Stack

- Python
- Google Colab (Jupyter Notebook)
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

📅 Week 1 – Data Preprocessing

Completed Activities

- Imported the dataset.
- Explored dataset structure and data types.
- Identified missing values.
- Checked duplicate records.
- Removed unnecessary columns.
- Handled missing values.
- Standardized the dataset.
- Prepared clean data for analysis.

---

📅 Week 2 – Exploratory Data Analysis

Completed Activities

- Performed descriptive statistics.
- Analyzed feature distributions.
- Created histograms and box plots.
- Compared important health indicators.
- Built a correlation heatmap.
- Identified trends and relationships within the data.
